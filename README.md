# PATHOS – Prototype AGV for Hospital Transport

## Overview

PATHOS (Patient Transport & Hospital Operating System) is a prototype Automated Guided Vehicle (AGV) developed for hospital transport applications. The system focuses on autonomous movement along a predefined path, load detection, and automated lifting mechanism integration.

This project was developed as an engineering prototype to explore robotic automation solutions for improving medical supply and patient transport efficiency.

## Features

- Line-following navigation using infrared sensor array
- Obstacle and object detection using distance sensors
- Automated lifting mechanism for transporting loads
- Microcontroller-based motor and actuator control
- Sensor-actuator integration for robotic operation

## Hardware Components

- Arduino microcontroller
- Infrared line sensors
- Ultrasonic sensor
- DC motors
- Motor driver
- Servo motor for lifting mechanism
- Mechanical lifting platform

## Software

- Arduino C/C++
- PID-based line following control
- Sensor feedback processing
- Motor control logic

## System Workflow

1. Robot follows predefined navigation paths.
2. Sensors continuously monitor line position and surrounding conditions.
3. The system detects objects placed on the platform.
4. The lifting mechanism activates to handle the load.
